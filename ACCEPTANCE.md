# Pencil acceptance

The first-release journey must durably support native operator sign-in, editing and branching, isolated preview, immutable publication, validated direct and embedded responses, quarantine review, factual reports, invitations/reminders, privacy erasure and portable data recovery. Features deferred by the contract profile are omitted. An offered, implemented feature whose optional adapter is absent names its unavailable state and enabling variables; required configuration still fails startup under WS-003. A new response sends one email to each operator who asked for it, and the sender being unusable never stops collection. Operators turn results into owned actions with frozen evidence counts, record measurements and set the verdict themselves; an external task leaves only after its exact JSON is confirmed, through the webhook adapter when `TASK_PROVIDER`, `TASK_WEBHOOK_URL` and `TASK_API_KEY` are set, and with its delivery state, every attempt and one idempotency key per action recorded. Recommendations come from operators (ACT-008) or from a validated analysis run (ANLY-006): an operator requests analysis of a revision's completed responses, every displayed count is recomputed and every quote verified against the stored answer before the run completes, themes below the disclosure threshold are withheld, and an operator turns the one recommendation into an action they own. Analysis is off until a provider is configured; nothing is sent until then.

`contract-profile.json` defers exactly ANLY-009 (builder assistance), NOTIFY-001 and NOTIFY-003 (3 clauses). Deferred means unfulfilled. These remain TODOs and `pnpm verify:contract:full` must fail until implemented. Every baseline requirement and every other product clause remains active. HOME-001 defaults optional static credit off; operators can enable it explicitly.

Run the complete `pnpm verify` gate with its original assertions, workload and thresholds. Local synthetic mail verifies protocol and application behavior. A hosted probe ran on 13 October 2026 against `cb5847d` plus a local-only `deploy.json` mail-provider change. It passed deployment and health, owner sign-in and setup, a six-row Typeform import with repeat and undo, a 5,000-row import on its second try, and export/restore; teardown returned the account resources to their original state. That probe was not the exact current head and sent only the sign-in link, not a new-response notification. The exact-head thirteen-stage proof remains incomplete; live new-response delivery and full hosted capacity remain unproven. The 5,000-row import ran close to the Worker CPU limit. A real account export and hidden-field behavior also remain unverified; the sign-in link is the only live mail result claimed.
